# Srikar Devaki — Portfolio

Personal portfolio website built with plain HTML, CSS, and vanilla JavaScript.

## Live Site
Deployed on Vercel.

## Tech Stack
- HTML5
- CSS3 (with custom spring physics & animations)
- Vanilla JavaScript

## Run Locally
```bash
# No build step needed — just open in browser
open index.html
# Or serve with Python
python -m http.server 8000
```
